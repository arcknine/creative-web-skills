# Common visual failures and remedies

| Failure | Evidence | Targeted remedy |
| --- | --- | --- |
| Weak hero | Headline, media, and CTA carry equal weight | Choose one focal point; change scale, crop, contrast, and support weight around it |
| Timid typography | Narrow size range and generic wraps | Increase role contrast, tune measure/line-height, and compose deliberate breaks |
| Excessive symmetry | Every section mirrors a centered axis | Introduce an offset anchor or unequal media/text relationship where the story supports it |
| Generic cards | Interchangeable bordered rectangles dominate | Choose a content-native form: index, sequence, annotated media, comparison, or roster |
| Repetitive rhythm | Identical padding and section skeletons | Alternate density, scale, media behavior, and transition type |
| Too many containers | Nested boxes weaken the field | Remove wrappers that do not group or constrain meaningfully; allow strategic full bleed |
| Bad crop | Subject, gaze, or action is cut off | Set breakpoint-specific ratio, source, and focal `object-position` |
| Awkward whitespace | Gaps do not frame or separate meaning | Re-anchor adjacent elements and derive spacing from section rhythm |
| Misaligned baselines | Nearby labels, type, and media edges almost align | Use shared grid anchors and optical adjustments at the responsible component level |
| Unreadable overlay | Text crosses high-detail or low-contrast image regions | Reframe crop, move copy, add localized scrim, or choose another asset |
| Stacked-desktop mobile | Page becomes long, repetitive, and loses focal order | Recompose, reorder, recrop, remove secondary layers, and simplify motion |
| Decorative noise | Marks, glow, or texture lack a role | Tie decoration to a motif/alignment/motion path or remove it |
| Slow motion | Interaction waits on ornamental sequencing | Prioritize response, shorten duration/stagger, and separate feedback from spectacle |
| Aggressive motion | Content moves far, often, or against scroll | Reduce amplitude/frequency, add stillness, and preserve native control |
| Weak contrast | Content disappears in normal or state variants | Correct color roles and overlays; verify focus, hover, disabled, and imagery states |

Diagnose the underlying system before patching a single viewport. Fix type tokens, grid rules, crop strategy, or repeated components when they cause multiple rows in this table.

## Diagnose genericity as a system

Do not label a page "AI-generated" merely because it uses cards, gradients, or a centered element. Cite the repeated defaults that make the result interchangeable.

- **Archetype leakage:** the page follows a SaaS sequence—hero, logo strip, three benefits, testimonials, pricing—even when the actual product needs a different narrative.
- **Component entropy:** unrelated content is forced into the same card, radius, icon, and spacing treatment until priority disappears.
- **Hero-only identity:** the first viewport has expressive art direction but every later section returns to framework-demo composition.
- **Effect dependency:** removing glow, gradient, shadow, and animation also removes the page's identity.
- **Content indifference:** headings, imagery, layout, and interaction could be replaced with another industry's content without structural change.

Prescribe a root correction: reorder the narrative around the user's decision, define recurring type/composition/interaction signatures, replace generic containers with content-native forms, and carry those signatures through at least two later sections. Verify the correction in the full-page capture, not only a hero crop.
